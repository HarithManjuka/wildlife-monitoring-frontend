# Smart Wildlife Conservation System - Operations Portal

The frontend interface for the Smart Wildlife Conservation System. This application serves as a hybrid portal providing specialized views for Field Rangers on mobile devices and Desktop Dashboards for Park Managers and Liaison Officers.

## 📱 Modules & Interfaces

1. **Ranger Mobile App - Field Patrols** (Implemented by M.U. Handaragama - IT23819092)
   - Mobile-optimized interface for logging incidents (poaching, snares).
   - Offline-first design with a sync-manager queue interface.
2. **Ranger Mobile App - Sensor Alerts** (Implemented by K.M.S.G.S.C. Karunanayake - IT23818620)
   - Real-time geographical threat display mapping animal proximity.
   - One-touch dispatch and acknowledgment workflows.
3. **Liaison Officer Dashboard - Conflict Reports** (Implemented by A.M.H.M. Abeykoon - IT23831254)
   - Desktop view for triaging incoming community intelligence.
   - Interface for adjusting threat severity and assigning Ranger units.
4. **Park Manager Dashboard - Analytics** (Implemented by J.R.I.C.S. Jayakody - IT23839106)
   - Data visualization suite (Hotspot heatmaps, incident trend charts).
   - Advanced filtering controls and export capabilities (PDF/CSV).

## 🚀 Tech Stack
* **Framework:** React.js (Vite)
* **Styling:** Tailwind CSS / CSS Modules
* **Icons:** Lucide React
* **State Management:** React Context API
